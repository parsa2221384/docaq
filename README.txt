# Document QA System

Django-based document question answering system using RAG.

## Technologies

- Django
- Django REST Framework
- LangChain
- Chroma
- Sentence Transformers
- OpenRouter

## Features

- Create, update and delete documents
- DOCX file upload
- Full document text extraction and storage
- Semantic search
- Vector retrieval
- Retrieval-Augmented Generation (RAG)
- LLM-based question answering
- Question and answer history
- Django Admin
- REST API
- Swagger API documentation
